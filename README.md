# TDL 투어 가이드 (TDL_Operator)

TDL LAB(Tech Driven Logistics) 투어를 **누가 맡아도 같은 품질**로 진행하기 위한 웹앱입니다.
투어 전 준비 → 투어 중 나레이션·스펙·Q&A → 투어 후 정리·기록을 한 곳에서 관리하고,
투어에서 받은 질문을 계속 쌓아 가이드를 보완합니다.

## 화면 구성
| 메뉴 | 내용 |
|---|---|
| ① 투어 전 | 공통 준비 체크리스트, 설비별 카드(사전 오더 · 전원 ON · 오더 업로드 경로 · 오류 대처), 비상연락망 |
| ② 투어 중 | 도면 위 동선과 장소 핀. 장소마다 나레이션(축약/풀버전) · 스펙(표준양식) · Q&A · 체크(가이드 행동, 영상, 비즈니스) |
| ▶ 투어 모드 | 휴대폰용 진행 화면. 큰 글씨 나레이션, 장소별 목표 시간 타이머, 이전/다음, 받은 질문 바로 메모(＋Q), 마무리 멘트 |
| ③ 투어 후 | 설비별 정리 · 전원 OFF, 투어 기록(받은 질문을 “장소번호: 질문”으로 적으면 Q&A에 확인필요로 자동 등록) |
| Q&A | 전체 질문 검색 · 장소/공통/확인필요/최근 수정 필터 |
| 더보기 | 투어 동선(Flowgram) 그리기, 데이터 내보내기/가져오기, PowerApps용 CSV, 설정, 변경 이력·되돌리기 |

- **접속 비밀번호**: 처음 들어올 때 입력. Apps Script(서버)에서 확인합니다.
- **편집 모드**: 오른쪽 위 🔒 편집 → 편집 비밀번호(기본 `0000`) + 작성자 이름. 모든 수정은 작성자·시각과 함께 시트의 history 탭에 남고 되돌릴 수 있습니다.
- **이동 멘트**: 같은 장소라도 동선(일반/VIP)에 따라 다음 장소로 넘어가는 멘트가 다르므로, 나레이션 아래에 동선별로 따로 보여 줍니다.
- **수정됨 배지**: 최근 N일(기본 30일, 설정에서 변경) 안에 수정된 항목에 표시됩니다.
- **확인필요**: 매뉴얼에 “00”, “000”처럼 비어 있는 수치는 주황색으로 강조되고, 값이 서로 다른 항목은 “확인필요”로 표시됩니다.

## 구조 (데이터는 구글 시트에만)
```
GitHub Pages (이 저장소: 코드만, 공개)  ──POST──▶  Apps Script 웹앱  ──▶  구글 시트 TDL_Operator
                                          접속·편집 비밀번호 확인          탭 = 테이블
```
- 이 저장소에는 **투자비·고객사 등 데이터와 비밀번호가 없습니다.** 모두 구글 시트와 Apps Script 스크립트 속성에만 있습니다.
- 웹앱 URL만 알아서는 데이터를 볼 수 없고, **접속 비밀번호**를 넣어야 시트 데이터를 받아옵니다.
- 휴대폰에서는 마지막으로 받은 데이터를 기기에 보관해, 현장에서 인터넷이 끊겨도(같은 비밀번호로) 볼 수 있습니다.

설치 방법 → [docs/setup.md](docs/setup.md)

## PowerApps 이관
모든 데이터는 평평한 테이블이며 테이블 하나가 SharePoint 목록 하나에 대응합니다. → [docs/powerapps-migration.md](docs/powerapps-migration.md)

## 폴더
```
index.html            앱 진입점
css/app.css           스타일 (모바일 우선, 다크 모드)
js/store.js           데이터 저장소 · 변경 이력 · 내보내기
js/floorplan.js       도면(원본 레이아웃을 벡터로 다시 그림) · 동선 렌더링
js/views-tour.js      투어 중 · 장소 상세 · 투어 모드
js/views-manual.js    투어 전 / 투어 후 · 투어 기록
js/views-misc.js      Q&A · 동선 편집기 · 더보기
js/views-gate.js      시트 연결 · 접속 비밀번호 · 초기 데이터 업로드 화면
config.js             Apps Script 웹앱 URL
apps-script/Code.gs   구글 시트에 붙여넣는 Apps Script
```
